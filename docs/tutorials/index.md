# Tutorials

Each tutorial builds a complete, working project from an empty folder. They assume you have done
[Your first RAG pipeline](../get-started/first-pipeline.md).

| Tutorial | You'll build | Needs |
|---|---|---|
| [Chat with a PDF](chat-with-pdf.md) | A terminal chatbot that answers questions about any PDF, with follow-ups and page citations | Groq key (free) |
| [Fully local RAG with Ollama](local-rag.md) | A private pipeline where nothing leaves your computer | Ollama |
| [Streamlit chat app](streamlit-app.md) | A web app: upload documents, chat, see sources | Groq key (free) |
| [Question answering over a website](website-qa.md) | Crawl a documentation site and answer questions about it | Groq key (free) |
| [Chatbot API with FastAPI](fastapi-chatbot.md) | An HTTP API with one conversation per user | Groq key (free) |
| [Evaluate and improve your RAG](evaluate-and-improve.md) | A test set, metrics, and measured improvements | Groq key (free) |

The [`examples/`](https://github.com/rithvikkatpelly/ragfoundry/tree/main/examples) folder in the
repository has more runnable scripts.
