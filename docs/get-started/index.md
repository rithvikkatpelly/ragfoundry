# Get started

This section takes you from zero to a working RAG pipeline. No prior experience with RAG,
embeddings or vector databases is needed; you only need to know basic Python.

Follow the pages in order:

1. **[What is RAG?](what-is-rag.md)**: the idea in plain language, with a diagram. 5 minutes.
2. **[Installation](installation.md)**: set up Python and install ragfoundry. 5 minutes.
3. **[API keys](api-keys.md)**: get a free key for an LLM, or use a local model. 5 minutes.
4. **[Your first RAG pipeline](first-pipeline.md)**: build one, line by line. 10 minutes.
5. **[Core concepts](concepts.md)**: what each part does and the words you will see.
6. **[Choosing components](choosing-components.md)**: which embedding model, vector store and
   LLM to use for your project.

After that, try a complete project in the [Tutorials](../tutorials/index.md).

!!! tip "Just want to see it work?"
    Open the [Colab notebook](https://colab.research.google.com/github/rithvikkatpelly/ragfoundry/blob/main/examples/colab_quickstart.ipynb)
    and run it in your browser. Nothing to install.
